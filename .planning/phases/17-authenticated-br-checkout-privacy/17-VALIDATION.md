## 2. Sampling Rate & Wave Structure

- **Structure:** 11 plans in **11 serial waves (Waves 0 to 10)**:
  `17-01 (W0) → 17-02 (W1) → 17-03 (W2) → 17-04 (W3) → 17-05 (W4) → 17-06 (W5) → 17-07 (W6) → 17-08 (W7) → 17-09 (W8) → 17-10 (W9) → 17-11 (W10)`.
- **Policy:** `parallelization=false`, max active implementation subagents = 1, `auto-chain=false`, `auto_advance=false`. Completing a plan does not authorize beginning the next.
- **Effort Policy:** Dynamic `orchestrator-selected: low | medium | high` per work unit (`recommended_default_effort` defined per plan).
- **After every task commit:** Run the directly affected unit or module test file.
- **After every plan wave:** Run the affected HTTP integration and disposable PostgreSQL suites.
- **Before Phase 17 Human Review Checkpoint:** Run the complete 17-point validation ledger.
- **Max feedback latency:** 30 seconds for normal per-task samples.
