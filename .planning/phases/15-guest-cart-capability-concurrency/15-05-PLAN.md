## Shared mutation pipeline (B15-P-HR-03) — lock for 15-05 and 15-06

Centralize in a helper/service (suggested path `line-item-mutation.ts`; executor may rename). Order is mandatory:

1. BFF already passed
2. Resolve actor (guest capability XOR Customer access context)
3. Assert `{id}` is that actor’s active cart (uniform 404 otherwise)
4. Parse + validate request/path semantics (**before claim**)
5. Require Idempotency-Key
6. `claim` (**before If-Match**)
7. Replay short-circuit: refetch canonical cart + current ETag; HTTP 200; NEVER re-emit capability; do not treat If-Match as a 412 gate on replay
8. Require If-Match (missing/malformed → 400 VALIDATION_ERROR)
9. CAS `compareAndSwapWithMutation` wrapping the Medusa workflow (`mutate` callback). Do not run the workflow outside CAS.
10. (workflow executes only inside the CAS mutate from step 9)
11. `applyStructuralCartInvalidation`
12. Terminalize idempotency claim
13. Refetch canonical cart
14. Serialize `PublicStoreCartPreOrder`
15. Current ETag

Execution subagent policy: see 15-01 `Phase 15 Execution Orchestration Policy`. This PLAN does not authorize EXECUTION.

### Claim lifecycle (existing machine only)

- success → `markCompleted`
- retryable failure → `markFailedRetryable`
- terminal failure → `markFailedTerminal`
- Do not invent a new idempotency state machine.

### Stale If-Match (deterministic `failed_terminal`)

First request with stale If-Match:

- `markFailedTerminal`
- `failure_code = CART_VERSION_MISMATCH`
- HTTP 412
- `PublicStoreCartPreOrder` current canonical snapshot
- current ETag
- zero mutation

Replay with same Idempotency-Key + same fingerprint:

- replay the **same** terminal failure
- HTTP 412
- current canonical snapshot
- current ETag
- zero mutation
- do **not** re-execute CAS/workflow

New intention:

- new Idempotency-Key
- new current If-Match

`Idempotency-Key` is not ownership.

### CART-09 helper — must exist BEFORE the first M1 mutation

`applyStructuralCartInvalidation(cartId, at)`:

- `invalidateActivePaymentAttemptForCartChange`
- `invalidateShippingQuote` no-op
- `invalidateShippingSelection` no-op

No Gelato, no network, no global mutable production counters only for tests. Prove invocation via spies/mocks/injection.

### Validator correction (B15-P-HR-05)

After JSON parse, `1` and `1.0` are the same Number. Do **not** assert that `1.0` fails. Test genuinely non-integer values: `1.5`, `1.1`, `98.9`. Matrix: add `1`/`99` pass; add `0` fail; update `0` removes; `-1`, `100`, `1.5` fail.

Staged counts after this plan: total 63, native identity 51, local 12, EXTENDED 15, DENY 48, PRESERVE_LEGACY 5, M1_ENABLED 10, nativeLocalExtension 4. The two promoted line-item keys were already EXTENDED while DENY; do not increment EXTENDED here. EXTENDED 15→16 happens only when 15-06 adds the new local DELETE collection.
