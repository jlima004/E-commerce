## Header contract (B15-P-HR-01)

Guest capability **request** header `x-indicio-guest-cart-token` on ALL six Cart M1 operations, `required: false` because Customer path exists:

- GET /store/carts/active
- POST /store/carts/active
- POST /store/carts/{id}/line-items
- POST /store/carts/{id}/line-items/{line_id}
- DELETE /store/carts/{id}/line-items/{line_id}
- DELETE /store/carts/{id}/line-items

Response header `x-indicio-guest-cart-token`:

- ONLY on guest mint **201** of POST active
- Replay **200**: NO capability response header
- GET: NO capability response header
- Mutations: NO capability response header

Never put token in examples. Flags `x-bff-only`, `x-not-browser-credential`, `x-sensitive` as schema extensions (not a second HTTP header). Swagger remains `nonInteractive` / `interactiveCandidate: false`.

POST active: Idempotency-Key required; 201 ETag + guest token response header; 200 replay without guest token response header.
Line-item ops: request token parameter (`required: false`) + If-Match + Idempotency-Key; 412 storeErrorResponse with cart `$ref PublicStoreCartPreOrder`.

operationIds when stable: `getActiveStoreCart`, `createActiveStoreCart`, `addCartLineItem`, `updateCartLineItem`, `removeCartLineItem`, `clearCartLineItems`.
